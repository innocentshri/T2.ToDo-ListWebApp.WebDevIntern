# Minimal To-Do List

A straightforward to-do list web application. I built this to have a lightweight task manager without dealing with the overhead of modern JavaScript frameworks or complex build tools.

## Features

* Built purely with vanilla JavaScript, HTML, and CSS to keep the codebase small and easy to maintain.
* Automatically saves your tasks to the browser's local storage, keeping your data intact across page reloads and browser sessions.
* Includes functional inline editing; you can update existing tasks by double-clicking the text or using the edit button, with support for keyboard shortcuts like Enter and Escape.
* Uses a responsive layout with a clean interface, relying on standard CSS variables and transitions instead of heavy external styling libraries.

## How to use it

Since there are no dependencies or build processes, setup is immediate:

1. Clone or download this repository.
2. Open `index.html` in your web browser.
3. Start adding tasks.
